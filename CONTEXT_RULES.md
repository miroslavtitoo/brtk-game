# CONTEXT_RULES.md — Правила работы с контекстом для Claude

## Обязательный протокол

1. **Начало сессии** — всегда читай `CLAUDE.md` первым делом. Это главный источник правды о проекте.

2. **Перед большими изменениями** — сверяйся с `ARCHITECTURE.md`, чтобы не сломать существующие паттерны и связи между модулями.

3. **После завершения задачи** — обнови `PROGRESS.md`:
   - Отметь выполненные пункты `[x]`
   - Добавь новые пункты, если появились
   - Обнови секцию «Известные баги» при необходимости

4. **Нетривиальное решение** — записывай в `DECISIONS.md`:
   - Формат: дата + решение + обоснование + отклонённые альтернативы
   - «Нетривиальное» = выбор между несколькими подходами, отход от плана, архитектурный компромисс

5. **Если что-то непонятно** — сначала ищи ответ в файлах проекта (`CLAUDE.md`, `ARCHITECTURE.md`, код), потом спрашивай пользователя.

## Дополнительные правила

- **Язык UI**: всегда русский (уведомления, меню, HUD-надписи)
- **Коммиты**: делай после каждого логического шага, не копи изменения
- **Тестирование**: после изменений проверяй через `npm run build` (TypeScript + Vite) и preview screenshot
- **Не ломай билд**: перед коммитом убедись, что `tsc` не выдаёт ошибок
- **Минимализм**: не добавляй лишний код, документацию, абстракции. Делай ровно то, что просят.
- **Конфиги**: все числа (урон, скорость, кулдауны) — в файлах `src/config/`, не захардкожены в логике
